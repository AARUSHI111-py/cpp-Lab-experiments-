To set up a GitHub repository and write a C++ program to demonstrate data types, constants, variables, operators and output.

## Theory
C++ is an object-oriented programming language.

- Variables store data values.
- Data types define the type of data stored.
- Constants are values that cannot be changed.
- Operators perform operations on variables and values.
- cout is used to display output.
